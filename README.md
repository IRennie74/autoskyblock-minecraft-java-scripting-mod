This repository contains an older version of my Minecraft Java mod developed between 2020–2022. It was my first large-scale Java project, originally built on top of a minimal “template-master” starter mod (hence the name). At the time, I didn’t yet know how to safely refactor large codebases, so the original structure remains.
While the code reflects early programming practices, the project includes a wide range of automation, customization, and reliability features. It was designed to run continuously for long periods without user intervention.

Features
Reliability & Safety Systems
- Server change detection
- Disconnection detection
- Automatic reconnection
- Automatic script restart on error
- False block detection
These systems were built to ensure long-term stability and uninterrupted operation.

Automation Scripts
Built‑in automation modes include:
- Side‑to‑side farming
- Side‑to‑side farming with forward/backward movement
- Cobblestone mining automation
- Automatic crafting
- Custom user-defined scripts

Keystroke & Movement Recording
A full input‑tracking system allows users to create highly accurate custom scripts:
- Records keyboard input every 5 ms
- Tracks mouse movement and player motion
- Replays actions with high precision
- Supports adding logic such as warping, server switching, and other automation layers

Notes
This project represents my introduction to large Java codebases, long‑running processes, and reliability engineering. Although some parts of the codebase reflect beginner‑level practices, the mod is feature‑rich, stable, and an important milestone in my growth as a developer.
